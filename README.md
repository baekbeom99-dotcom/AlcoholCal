# 알콜달력

귀여운 술병·캔 스티커로 마신 양을 기록하는 PWA 달력이에요.

- 화면 아래 술병을 한 번 누르면 선택한 날짜에 한 병(캔)이 붙어요.
- 여럿이 마셨다면 인원을 먼저 맞춰두세요. 한 번 누를 때마다 1/n병씩 기록돼요.
- 기록은 이 기기의 브라우저에만 저장돼요. 기기를 바꾸기 전에 "백업 저장"을 해두세요.

## 로컬 실행

```bash
node server.js
```

`http://localhost:5173`에서 열려요.

## 배포

GitHub Pages가 `main` 브랜치 루트를 그대로 배포해요. 파일을 고친 뒤에는 `sw.js`의 `VERSION`을 올려야 설치된 앱에도 새 버전이 반영돼요.
